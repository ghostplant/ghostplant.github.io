# Tank 1990 · 坦克大战

一个用 HTML5 Canvas 实现的经典坦克大战游戏，灵感来自 1990 年的经典坦克大战（Battle City / Tank 1990）。

## 特性

- **纯前端实现**：HTML + CSS + JavaScript，无需后端，无需安装依赖
- **程序化像素美术**：所有图形通过 Canvas API 绘制，无需外部图片素材
- **Web Audio 音效**：所有音效通过 Web Audio API 合成，无需音频文件
- **8 个关卡**：包含砖墙、钢墙、水域、树林等多种地形
- **4 种敌机**：普通、快速、强力、装甲（装甲敌机需要多次击中）
- **6 种道具**：星星（升级）、炸弹（全屏清敌）、时钟（冻结敌人）、铁铲（基地钢化）、坦克（加命）、护盾（无敌）
- **道具携带者**：部分敌机会携带道具（红色闪烁），击毁后掉落
- **玩家升级**：收集星星可升级（最高 3 级），解锁更快子弹、双发、破钢墙能力

## 玩法

### 目标
保护基地（老鹰标志），消灭所有敌机。如果基地被摧毁或生命耗尽，游戏结束。

### 操作
| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → / W A S D | 移动坦克 |
| 空格 / J | 射击 |
| Enter | 开始 / 确认 |
| P | 暂停 |

### 道具说明
| 道具 | 效果 |
|------|------|
| ★ 星星 | 升级坦克（1级：加速子弹，2级：双发，3级：可破钢墙） |
| 💣 炸弹 | 摧毁屏幕上所有敌机 |
| ⏰ 时钟 | 冻结所有敌机 10 秒 |
| 🛡 铁铲 | 基地周围砖墙变为钢墙 15 秒 |
| 🛡 坦克 | 增加 1 条生命 |
| 护盾 | 玩家无敌 10 秒 |

### 敌机类型
| 类型 | 说明 | 分数 |
|------|------|------|
| 普通 (灰) | 基础敌机 | 100 |
| 快速 (白) | 移动速度快 | 200 |
| 强力 (绿) | 子弹速度快 | 300 |
| 装甲 (灰闪) | 需要 4 次击中 | 400 |

## 运行

直接在浏览器中打开 `index.html` 即可：

```
直接双击 index.html
```

或使用本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

然后访问 `http://localhost:8000`。

## 技术细节

- **网格**：26×26 格，每格 16 像素，画布 416×416
- **坦克**：32×32 像素（2×2 格）
- **关卡**：13×13 方块，每个方块展开为 2×2 格
- **固定时间步长**：60 FPS 逻辑更新
- **碰撞检测**：AABB（轴对齐包围盒）+ 网格碰撞

## 浏览器兼容

支持现代浏览器（Chrome、Firefox、Edge、Safari），需支持 Canvas 和 Web Audio API。
