01 / 基本操作

方向键 或 WASD 移动。碰到绿色 Base 会挖掉它，碰到 Infotron 会收集。凑够本关目标后进入 E 出口即可过关。

主角移动速度已提高到 1.3 倍，每格约 153.8 毫秒；落物仍每 200 毫秒下落一格。

空格 + 方向键：原地挖掘、收集相邻 Infotron 或红磁盘。P / Esc 暂停，R 重来，M 切换全图。

02 / 落石与支撑

Zonk 和 Infotron 会向下落，在圆形物体或芯片上会优先向左滚落，左边不通再向右。静止物体不会直接压死下方的 Murphy，但下落中的物体会。

本网页版在落物触顶时提供 200 毫秒的转向缓冲，并用橙线提示；持续站在落点或出口被堵仍会被砸中。快速输入“下→右”会按顺序执行。橙磁盘和敌人不享有此缓冲。

持续按左右方向可推动一块静止的 Zonk 或橙磁盘，前方必须为空。Infotron 不能推动，只能收集。

03 / 三种磁盘

橙磁盘会下落，落地后爆炸；黄磁盘能向四个方向推动，接触终端会引爆全关黄磁盘；红磁盘可以收集。

不按方向，按住 空格 或 B 约 0.6 秒放置红磁盘，约 3 秒后爆炸。一次只能放一颗，放好后及时离开。

04 / 敌人与爆炸

Snik Snak 和 Electron 只在空地巡逻，遵循左手沿墙规则。剪刀直行时保持朝向并张合，实际拐弯时才播放对应转身，静止或冻结时不旋转。撞上敌人会失败。下落的重物可以引爆它们。

爆炸影响中心周围的九宫格，会破坏电路、芯片等并触发连锁；硬件墙不可破坏。Electron 爆炸后会留下 Infotron。Bug 安静时可挖，闪动时触碰会爆炸。

05 / 通道与重力

按箭头方向穿过单向通道，另一端必须为空。双向和四向通道按其标记通行。特殊通道可能切换重力、冻结落石或敌人。

重力开启时只要脚下是空地就会下落，但可通过挖侧面或上方的 Base 攀附；从向上传送口出来也可悬挂。落石的重力始终存在。

06 / 触摸与进度

触屏使用下方方向键；“原地收集”是开关，打开后点方向键即可挖掘相邻格；“按住放弹”用于放红磁盘。

打开指南、切换窗口会自动暂停。通关成绩保存在浏览器本地；不保存游戏中途状态。所有关卡默认开放。

ABOUT THIS EDITION

老游戏的新入口。

这不是 DOS 模拟器，也没有运行原压缩包里的 EXE、BAT 或其他可执行文件。图像、配色和 111 个 60 × 24 关卡均来自你提供的压缩包，游戏逻辑以 JavaScript + Canvas 重新实现。

还原范围

包含收集与出口、原地挖掘、落石与滚落、三种磁盘、终端、连锁爆炸、巡逻敌人、Electron 产出 Infotron、Bug、单/双/四向通道，以及特殊通道的重力与冻结状态。

与 DOS 原版的差异

世界逻辑保持 200 毫秒一步，主角独立按约 153.8 毫秒一步移动，各自使用插值动画，不是原程序的逐帧移植。敌人转身、碰撞时机、Bug 周期和爆炸时序存在差异；没有还原内存越界技巧、原版录像、存档和原版音频。音效为浏览器合成，可关闭。全部原版关卡已导入，但未逐关证明可解，不保证原版录像或极限操作路线兼容。
